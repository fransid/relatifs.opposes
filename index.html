Nombres relatifs : opposés, sommes et symétriques

Exercice de Sid KHALIFA

Mathématiques – Niveau 5e (cycle 4) – Nombres relatifs
Consigne : écris tes réponses dans les cases (utilise la virgule ou le point pour les décimaux, le signe « − » ou « - » pour les négatifs ; le « + » est facultatif). Appuie sur Entrée ou clique ailleurs : la case devient verte si la réponse est juste, rouge sinon.
Score : 0 / 0

Corrigé détaillé

Rappel : deux nombres sont opposés s'ils ont la même distance à zéro mais des signes contraires.

Exercice 1 — Donner l'opposé

a) L'opposé de +7,5 est −7,5

b) L'opposé de −4,25 est +4,25

c) L'opposé de 0 est 0 (0 est le seul nombre égal à son opposé)

d) L'opposé de +0,05 est −0,05

e) On simplifie d'abord : −(−6,8) = +6,8, donc l'opposé est −6,8

f) On simplifie d'abord : −(+3,4) = −3,4, donc l'opposé est +3,4

Exercice 2 — Reconnaître des opposés

a) Oui : même distance à zéro (9,5) et signes contraires.

b) Non : les signes sont identiques ; ces deux nombres sont égaux.

c) Non : les distances à zéro sont différentes (3,75 et 3,57).

d) Oui : −(−2,6) = +2,6, et +2,6 et −2,6 ont même distance à zéro et des signes contraires.

e) Non : les distances à zéro sont différentes (0,1 et 0,01).

Exercice 3 — Simplifier une écriture

a) −(+4,5) = −4,5 ; distance à zéro : 4,5

b) −(−12,75) = +12,75 ; distance à zéro : 12,75

c) +(+0,8) = +0,8 ; distance à zéro : 0,8

d) +(−0,6) = −0,6 ; distance à zéro : 0,6

Exercice 4 — Symétriques par rapport à l'origine O

Le symétrique d'un point par rapport à O se place à la même distance de O, de l'autre côté : son abscisse est l'opposé de celle du point de départ. O est le milieu de chaque segment [AA′], [BB′], [CC′] et [DD′].

A′ a pour abscisse −3 (opposé de +3)

B′ a pour abscisse +2,5 (opposé de −2,5)

C′ a pour abscisse −1,5 (opposé de +1,5)

D′ a pour abscisse +0,5 (opposé de −0,5)

Exercice 5 — Symétrique par rapport à un point

a) Le symétrique de A par rapport à O a pour abscisse l'opposé de +5 : −5.

b) L'abscisse de C est l'opposé de −1,5 : +1,5.

c) B doit être le milieu de [AE] : −1,5 = (+5 + xE) ÷ 2, d'où +5 + xE = −3, donc xE = −8.
Vérification : (−8 + 5) ÷ 2 = −1,5. On peut aussi compter : de B (−1,5) à A (+5) il y a 6,5 unités ; on reporte 6,5 unités avant B : −1,5 − 6,5 = −8.

d) Distance AB = +5 − (−1,5) = 5 + 1,5 = 6,5 unités.

Exercice 6 — Somme de deux nombres relatifs

Signes identiques : on garde le signe et on additionne les distances à zéro. Signes contraires : on garde le signe de celui qui a la plus grande distance à zéro et on soustrait les distances à zéro.

a) Signes identiques (+) : (+5,5) + (+2,5) = +8

b) Signes identiques (−) : (−3,2) + (−4,8) = −8

c) Signes contraires : 9,5 > 7,5, donc le résultat est négatif ; 9,5 − 7,5 = 2 : (+7,5) + (−9,5) = −2

d) Signes contraires : 10,4 > 6,4, résultat positif ; 10,4 − 6,4 = 4 : +4

e) Deux nombres opposés : leur somme vaut 0

Exercice 7 — Soustraction de nombres relatifs

Soustraire un nombre, c'est ajouter son opposé : a − b = a + (−b).

a) (+6,3) − (+9,8) = (+6,3) + (−9,8) = −3,5

b) (−4,5) − (+2,5) = (−4,5) + (−2,5) = −7

c) (−7,1) − (−3,6) = (−7,1) + (+3,6) = −3,5

d) (+2,05) − (−0,95) = (+2,05) + (+0,95) = +3

Exercice 8 — Sommes algébriques

On supprime les parenthèses en appliquant la règle des signes, puis on calcule étape par étape.

A = 7,5 − 3,5 − 5,5 − 1,5 : 7,5 − 3,5 = 4 ; 4 − 5,5 = −1,5 ; −1,5 − 1,5 = −3

B = −2,25 − 1,75 − 0,5 + 6,5 : −2,25 − 1,75 = −4 ; −4 − 0,5 = −4,5 ; −4,5 + 6,5 = +2

C = −4,75 + 2,25 − 1,5 + 4 : −4,75 + 2,25 = −2,5 ; −2,5 − 1,5 = −4 ; −4 + 4 = 0

Exercice 9 — Problèmes

1. Monter de 45,5 m revient à ajouter +45,5 ; descendre de 62,5 m revient à ajouter −62,5 :
−150 + 45,5 − 62,5 = −104,5 − 62,5 = −167 m. Le sous-marin se trouve à 167 m de profondeur.

2. Déposer 50 € revient à ajouter +50 ; un prélèvement de 12,75 € revient à ajouter −12,75 :
−35,5 + 50 − 12,75 = 14,5 − 12,75 = +1,75 €. Le solde est positif : le compte est à nouveau créditeur.

Exercice 10 — Bilan sur une droite graduée

a) E a pour abscisse −4,5 ; F a pour abscisse +4,5 ; G a pour abscisse +1,5.

b) E et F sont symétriques par rapport à O : leurs abscisses sont opposées (−4,5 et +4,5), donc O est le milieu de [EF].

c) H est le symétrique de G(+1,5) par rapport à O, donc son abscisse est l'opposé de +1,5 : −1,5.

d) EF = (+4,5) − (−4,5) = 4,5 + 4,5 = 9 unités. EG = (+1,5) − (−4,5) = 1,5 + 4,5 = 6 unités.

e) F doit être le milieu de [GM] : (+1,5 + xM) ÷ 2 = +4,5, d'où +1,5 + xM = +9, donc xM = +7,5.
Autre méthode : de G (+1,5) à F (+4,5) il y a 3 unités ; on reporte 3 unités après F : 4,5 + 3 = 7,5.

À retenir
• Opposé d'un nombre : même distance à zéro, signes contraires. Exemple : l'opposé de +7,5 est −7,5.
• Symétrique par rapport à O : le point symétrique de M a pour abscisse l'opposé de celle de M ; O est le milieu du segment formé.
• Le seul nombre égal à son opposé est 0.
• Soustraire, c'est ajouter l'opposé : a − b = a + (−b).
• Distance entre deux points : plus grande abscisse − plus petite abscisse.
• Symétrique par rapport à un point A : A est le milieu du segment formé par le point et son image.
